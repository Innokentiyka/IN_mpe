# ИН МЭИ — сайт программы наставничества

Адаптивный публичный сайт Института наставничества МЭИ на HTML, CSS и JavaScript без внешних библиотек. Сейчас это готовая презентационная версия: программа и этапы отбора, карточки событий, FAQ и переход к официальным новостям. Интерактивны мобильная навигация и раскрывающиеся ответы.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Нужен Python 3; установка пакетов не требуется.

## Развитие

Дальше можно добавлять регистрацию и авторизацию, профиль, календарь интервью, статусы, материалы, административную панель, рабочее место интервьюера, уведомления и агрегированную отчётность. Перед подключением реальных форм и данных сначала реализуйте серверное API, хранилище, вход, роли и защиту от повторного бронирования. См. `SECURITY.md`.

Логотип взят из приложенного брендбука. Цвета следуют брендбуку; корпоративные шрифты не приложены, поэтому CSS содержит системные замены.
