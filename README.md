# ИН МЭИ — система отбора наставников

Рабочий MVP на Python 3 и SQLite. Есть публичные события и материалы, регистрация пользователей, профиль, защищённые сессии, запись на интервью и аттестацию, запись на мероприятия с учётом вместимости, учёт посещения, уведомления, роли кандидата/наставника/интервьюера/администратора, расписание, результаты, оценки и сводные показатели.

## Первый запуск

В корне checkout создайте администратора:

```sh
python3 server.py create-admin
```

Укажите свой телефон и имя, затем задайте пароль длиной не менее 12 символов. Пароль вводится скрыто и не попадает в историю команд. Эта команда создаёт администратора именно в базе данных этого checkout. Для запуска сервера:

```sh
python3 server.py
```

Откройте `http://127.0.0.1:8000` — не открывайте `index.html` двойным щелчком и не используйте GitHub Pages для регистрации: там нет backend API. Требуется Python 3.10+. В Windows сначала установите базу часовых поясов: `py -m pip install tzdata`. В macOS/Linux достаточно Python с системной базой часовых поясов. SQLite база `data/in_mpe.sqlite3` создаётся автоматически, хранит учётные записи, расписание, события, записи и уведомления и исключена из Git. Чтобы перенести данные, сохраните резервную копию этого файла при остановленном сервере. Для другого адреса, порта и файла БД задайте `HOST`, `PORT`, `IN_MPE_DB`.

Сервер по умолчанию слушает только localhost, поэтому подходит для разработки на вашем компьютере. Чтобы сайт был доступен другим пользователям, нужен размещённый backend и SQLite на сервере (или миграция на управляемую SQL-БД), домен и HTTPS reverse proxy; GitHub Pages содержит только файлы интерфейса. Выставьте `COOKIE_SECURE=true`, ограничьте доступ к порту backend и настройте резервное копирование. Не открывайте стандартный HTTP сервер напрямую в интернет. Перед реальной эксплуатацией заполните необходимые сведения оператора и хранения данных в `privacy.html`.

## Основные сценарии

- Кандидат регистрируется по телефону, заполняет профиль, выбирает свободный интервал и отслеживает статус/уведомления.
- Администратор в личном кабинете управляет статусами и ролями, создаёт/отменяет интервалы и события, публикует материалы, назначает интервьюера и смотрит результаты/оценки.
- Интервьюер видит только назначенные ему записи и может сохранить итог интервью; оценки доступны администратору.
- Запись ограничена вместимостью слота транзакцией базы данных. У кандидата может быть только одна активная запись.

Чтобы выдать роль интервьюера, администратор открывает карточку пользователя и меняет роль на «Интервьюер», затем назначает этого сотрудника при создании интервала.

Пароль забыт? В MVP нет email/SMS восстановления: после проверки личности пользователя оператор сервера выполняет `python3 server.py reset-password`, вводит телефон и задаёт новый пароль в скрытом prompt. Команда завершает активные сессии аккаунта. Не присылайте пароль обычным сообщением.

## Структура

- `server.py` — HTTP API, аутентификация, права доступа и база данных.
- `index.html`, `public/` — публичный сайт и личные кабинеты.
- `privacy.html` — описание собираемых данных и незаполненные организационные условия до публичного набора.
- `SECURITY.md` — меры безопасности и эксплуатационные ограничения.

Компоненты разделены по API и таблицам SQLite: учётные записи/профили, интервалы/записи, уведомления, материалы/события и журнал действий. Новые каналы уведомлений, интеграции и файловое хранилище подключайте отдельными серверными модулями.
